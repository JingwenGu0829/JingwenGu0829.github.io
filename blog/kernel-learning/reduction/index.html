Kernel Learning · 01

Reduction

CuTe DSL · Multi-CTA reduction with atomic aggregation

Problem

Given a contiguous one-dimensional tensor of N float32 values, compute their sum and write the result to output[0].

Source: LeetGPU — Reduction ↗. Challenge definition: AlphaGPU/leetgpu-challenges ↗.

1. Execution model & dataflow

The reduction narrows the tensor hierarchically: each level emits fewer partial sums before the final GPU-wide atomic aggregation.

2. Current solution

v02_multi_cta_atomic.py Python · CuTe DSL 
import cutlass
import cutlass.cute as cute


BLOCK_SIZE = 256
GRID_SIZE = 132 * 8
WARP_SIZE = 32
WARPS_PER_BLOCK = BLOCK_SIZE // WARP_SIZE


@cute.jit
def warp_sum(value: cutlass.Float32) -> cutlass.Float32:
    value += cute.arch.shuffle_sync_down(value, offset=16)
    value += cute.arch.shuffle_sync_down(value, offset=8)
    value += cute.arch.shuffle_sync_down(value, offset=4)
    value += cute.arch.shuffle_sync_down(value, offset=2)
    value += cute.arch.shuffle_sync_down(value, offset=1)
    return value


@cute.kernel
def clear_output_kernel(output: cute.Tensor):
    """Give the following atomic reduction a defined identity value."""
    output[0] = cutlass.Float32(0.0)


@cute.kernel
def reduction_kernel(
    input: cute.Tensor,
    output: cute.Tensor,
    N: cute.Int32,
):
    thread_idx, _, _ = cute.arch.thread_idx()
    block_idx, _, _ = cute.arch.block_idx()
    grid_size, _, _ = cute.arch.grid_dim()
    lane_idx = cute.arch.lane_idx()
    warp_idx = cute.arch.warp_idx()

    thread_sum = cutlass.Float32(0.0)
    index = block_idx * BLOCK_SIZE + thread_idx
    grid_stride = grid_size * BLOCK_SIZE
    while index < N:
        thread_sum += input[index]
        index += grid_stride

    thread_sum = warp_sum(thread_sum)

    smem = cutlass.utils.SmemAllocator()
    warp_sums = smem.allocate_tensor(cutlass.Float32, WARPS_PER_BLOCK)
    if lane_idx == 0:
        warp_sums[warp_idx] = thread_sum

    cute.arch.sync_threads()

    if warp_idx == 0:
        block_sum = cutlass.Float32(0.0)
        if lane_idx < WARPS_PER_BLOCK:
            block_sum = warp_sums[lane_idx]
        block_sum = warp_sum(block_sum)

        if lane_idx == 0:
            cute.arch.atomic_add(
                output.iterator,
                block_sum,
                sem="relaxed",
                scope="gpu",
            )


@cute.jit
def solve(input: cute.Tensor, output: cute.Tensor, N: cute.Int32):
    """LeetGPU entry point: clear output, then reduce with many CTAs."""
    clear_output_kernel(output).launch(
        grid=[1, 1, 1],
        block=[1, 1, 1],
    )
    reduction_kernel(input, output, N).launch(
        grid=[GRID_SIZE, 1, 1],
        block=[BLOCK_SIZE, 1, 1],
    )

3. Takeaways

GPU programming model

  • Reduce hierarchically: thread registers → warp shuffle → CTA shared memory → one global atomic.
  • A grid-stride loop lets a fixed grid cover arbitrary N while keeping many CTAs resident.
  • Reducing inside the CTA first changes 256 potential atomics into one atomic per CTA.
  • sync_threads() is required before warp 0 reads the partials written by the other warps.
  • The atomic target is one float32 in HBM, so it must be initialized to the additive identity before accumulation.

CuTe DSL mental model

  • cute.Tensor carries a memory iterator plus layout; indexing maps coordinates onto that storage.
  • output.iterator points at the tensor's current origin—here, effectively &output[0].
  • shuffle_sync_down exchanges register values between lanes without shared memory.
  • SmemAllocator.allocate_tensor creates typed CTA-local scratch storage for the eight warp sums.
  • atomic_add(..., sem="relaxed", scope="gpu") provides atomicity across the GPU without unnecessary ordering guarantees.
